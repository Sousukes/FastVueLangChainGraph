# 阶段 00 · 环境与工具准备

> 本阶段是整门课的「第 0 章」，不计入 18 个正式阶段。
> 目标只有一个：**让你第一天就能在本地把环境跑通**，后面 18 个阶段不再被「装不上、跑不起来」卡住。

## ① 阶段目标

学完本阶段，你将能够：

- 安装并验证 Python 3.11+、Node.js 20、包管理器 `uv` 与 `pnpm`
- 申请 DeepSeek API Key 并安全地放入 `.env`（**绝不提交到 git**）
- 用不到 10 行代码跑通第一次大模型调用，确认 Key 有效
- 在本地启动 VitePress 文档站，随时回看教程

## ② 前置知识 / 环境

你需要准备的工具与最低版本：

| 工具 | 版本 | 用途 |
|---|---|---|
| Python | 3.11+ | 后端 FastAPI |
| `uv` | 最新 | Python 依赖与虚拟环境管理（比 pip 快得多） |
| Node.js | 20 LTS | 前端 Vue3 / Vite / VitePress |
| `pnpm` | 最新 | 前端包管理 |
| Git | 任意较新版本 | 阶段分支管理 |
| 代码编辑器 | VS Code 推荐 | 写代码 |
| DeepSeek 账号 | — | 提供 API Key（阶段 00–17 默认模型） |

> 如果你是纯小白，先确认 **Python 和 Node 能在终端里输出版本号**即可，不必理解它们内部如何工作。

## ③ 核心概念（先讲清楚，后面才不会懵）

- **API Key**：调用大模型的「密码」。它代表你的账号和额度，**必须保密**——绝不能写进前端代码，也不能提交到 git。
- **base_url**：大模型服务的网络地址。DeepSeek 兼容 OpenAI 协议，地址为 `https://api.deepseek.com`。
- **messages（消息列表）**：大模型不是「一问一答」，而是接收一个**消息列表**，每条消息带 `role`（角色：`system`/`user`/`assistant`）和 `content`（内容）。
- **模型名**：本课程默认 `deepseek-flash`（具体 id 以 DeepSeek 平台当前值为准）。阶段 18 的 Computer Use 会单独用 Claude。
- **客户端（client）**：我们用 OpenAI 官方 SDK 访问 DeepSeek（因为 DeepSeek 兼容其协议），后续阶段会把它封装成「自封装 client」，但本阶段先用最直白的方式验证。

## ④ 动手实现（分步）

### 步骤 1：安装 `uv`（Python 依赖管理）

Windows（PowerShell）：

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.psm1 | iex"
```

macOS / Linux：

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

验证：

```bash
uv --version
```

### 步骤 2：安装 Node.js 20 + `pnpm`

1. 到 https://nodejs.org 下载 **LTS（20.x）** 安装包并安装。
2. 安装后用 Corepack 启用 `pnpm`：

```bash
corepack enable
corepack prepare pnpm@latest --activate
pnpm --version
```

验证 Node 与 pnpm：

```bash
node -v   # 应显示 v20.x
pnpm -v
```

### 步骤 3：申请 DeepSeek Key 并写入 `.env`

1. 打开 https://platform.deepseek.com ，注册并进入「API Keys」页面。
2. 创建一个 Key，复制形如 `sk-xxxx` 的字符串。
3. 在 `backend/` 目录下，复制 `.env.example` 为 `.env`，填入你的 Key：

```bash
cp backend/.env.example backend/.env   # macOS/Linux
# Windows: 直接复制文件并重命名为 .env
```

`backend/.env` 内容（只改 `DEEPSEEK_API_KEY`）：

```ini
DEEPSEEK_API_KEY=sk-你的真实key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
```

> ⚠️ `.env` 已在仓库 `.gitignore` 中，**不会被提交**。永远不要把 Key 贴进代码或聊天框。

### 步骤 4：最小验证脚本（第一次调用大模型）

在 `backend/` 下新建 `verify_key.py`：

```python
from openai import OpenAI
import os
from dotenv import load_dotenv

load_dotenv()  # 读取 .env

client = OpenAI(
    base_url=os.getenv("DEEPSEEK_BASE_URL"),
    api_key=os.getenv("DEEPSEEK_API_KEY"),
)

resp = client.chat.completions.create(
    model=os.getenv("DEEPSEEK_MODEL", "deepseek-flash"),
    messages=[{"role": "user", "content": "用一句话介绍你自己"}],
)

print(resp.choices[0].message.content)
```

创建隔离环境并运行（首次会自动装依赖）：

```bash
cd backend
uv venv
uv pip install openai python-dotenv
uv run python verify_key.py
```

### 步骤 5：启动文档站（VitePress）

回到仓库根目录：

```bash
cd docs
pnpm install
pnpm docs:dev
```

浏览器打开提示的地址（默认 `http://localhost:5173`），即可看到本教程首页。

## ⑤ 运行验证

- **步骤 4** 应打印出模型返回的一段中文介绍（证明 Key 有效、网络可达）。
- **步骤 5** 应在浏览器看到课程首页，侧边栏含「设计树 DESIGN」与「环境准备」。
- 运行 `git status`，应**看不到** `backend/.env`（说明它被正确忽略了）。

如果步骤 4 报错 `AuthenticationError`：检查 Key 是否复制完整、`.env` 是否在 `backend/` 目录。
如果报 `ImportError`：确认 `uv pip install` 步骤成功执行。

## ⑥ 小结

- 环境一次配好，后面 18 阶段都复用，无需重复。
- API Key 是「密码」，靠 `.env` + `.gitignore` 保管，绝不进代码库。
- DeepSeek 兼容 OpenAI 协议，所以我们可以直接用 OpenAI SDK 调用它——这是后续「自封装 client」的基础。
- 文档站与代码同仓，边学边查。
